# Abhinav Chauhan — Personal Portfolio

Personal site for Abhinav Chauhan (Principal SDET / Quality Engineering Leader).

## Stack

- Vite + vanilla HTML / CSS / JS
- Fonts: Instrument Serif, Outfit, JetBrains Mono
- Netlify-ready (`netlify.toml`)

## Local

```bash
npm install
npm run dev
```

## Deploy (Netlify)

- Build: `npm run build`
- Publish: `dist`

Or import https://github.com/abhinavchauhan2015-ship-it/abhinav-chauhan-portfolio from Git.
